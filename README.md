# Módulo 8 - Reto 2: Proyecto de Ciencia de Datos

Proyecto de Ciencia de Datos reproducible desarrollado con RStudio, GitHub y herramientas de investigación reproducible.

## Objetivo principal

Analizar la evolución de la población, la fertilidad y la mortalidad en los países de Latinoamérica seleccionados, mediante técnicas de Ciencia de Datos y visualización, con el fin de identificar patrones y diferencias demográficas entre países y a lo largo del tiempo.

## Objetivos específicos

1. Describir la evolución de la población de los países seleccionados durante el periodo disponible en las bases de datos.

2. Analizar la evolución de las tasas de fertilidad y mortalidad y observar sus diferencias entre los países estudiados.

3. Comparar los patrones demográficos entre países, identificando aquellos que presentan comportamientos similares o diferenciados.

4. Explorar la relación entre fertilidad, mortalidad y crecimiento poblacional, utilizando representaciones gráficas adecuadas para facilitar su interpretación.

5. Comunicar los principales resultados mediante visualizaciones, de manera que permitan identificar tendencias, diferencias y patrones demográficos de forma clara.
