# Código de Depuración
## Proceso de depuración de los datos
La depuración inicial de las bases de datos se realizó durante el Reto 1 del proyecto.
El proceso consistió en revisar las bases de datos originales y seleccionar manualmente los registros correspondientes a 19 países de Latinoamérica definidos para el análisis.
### Países seleccionados
- Argentina
- Bolivia
- Brazil
- Chile
- Colombia
- Costa Rica
- Cuba
- Dominican Republic
- Ecuador
- Guatemala
- Honduras
- Mexico
- Nicaragua
- Panama
- Peru
- Paraguay
- El Salvador
- Uruguay
- Venezuela
### Resultado
Como resultado del proceso de selección se obtuvieron las bases de datos depuradas que contienen únicamente la información correspondiente a los 19 países seleccionados.
Los archivos depurados se conservan en la carpeta `Base_Datos_Depurada`, mientras que los archivos originales se mantienen en `Base_Datos_Original` para preservar la trazabilidad del proyecto.

Este proceso permite mantener la separación entre los datos originales y los datos preparados para el análisis.
